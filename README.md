# ☢ TIO: Nacki

Пошаговая тактическая игра в духе **Total Influence Online** — для мобильных, бесплатно, с он-чейн профилем на блокчейне **Acki Nacki**.

## Что уже есть (играбельно прямо сейчас) — v2

- ⚔️ **Пошаговые бои на больших картах как в TIO**: от 15×15 до **21×21** (размер растёт со сложностью миссии и режимом арены: 1×1 — 15, 2×2 — 17, 4×4 — 21). Камера панорамируется пальцем/мышью и автоматически следует за выбранным бойцом. Очки действия (ОД), укрытия (-20% шансу попадания), линия огня, диагональное движение дороже.
- 🏚️ **Ангары и дома**: генерируются на каждой карте — стены из рифлёного металла с ржавыми подтёками и крышами, бетонные полы с масляными пятнами, **двери с жёлтой разметкой** (можно заходить внутрь — стены заслоняют и пули, и обзор: зачистка помещений!).
- 📦 **Лут-ящики в ангарах как в TIO**: армейские ящики со светящейся меткой ✦, вскрытие — 3 ОД вплотную. Внутри: аптечки, гранаты, оружие вплоть до СВД и M60. **Всё найденное живёт только до конца боя** — трофейный ствол бросается на выходе, найденные расходники сгорают, вынести с карты ничего нельзя (механика оригинала). Пёс найденную аптечку сразу съедает (+40 HP), гранату взять не может. Найденные расходники тратятся раньше своих.
- 🌿 **Красивое окружение**: пучки сухой травы, трещины и камешки на земле, бетон со швами внутри ангаров — всё в пререндере мира (не ест FPS на больших картах).
- 👁 **Туман войны и зрение как в оригинальном TIO**: врагов не видно, пока боец не подойдёт на дистанцию обзора с чистой линией видимости (укрытия заслоняют). Карта: неразведанное — почти чёрное, разведанное — полутень, видимое сейчас — светлое. Синяя кромка показывает границу зрения выбранного бойца. Враги тоже честно «не видят» отряд: патрулируют, идут на последнюю замеченную позицию (lastSeen), атакуют только в своём радиусе обзора. Гранату в туман бросить нельзя. Зрение: люди 👁6, **пёс 👁7** (разведчик), мутант 👁5, сталкер «Спектры» 👁7.
- 🪖 **5 классов наёмников** как в TIO: штурмовик, снайпер, тяжёлый, **боевой пёс** 🐕 (зрение 7, 15 ОД, усиленный укус 16–26 — лучший разведчик) и **мутант-шахтёр** 🧟.
- 📈 **Навыки оружия как в оригинальном TIO**: 5 веток — лёгкое 🔫, автоматическое 🔥, тяжёлое 💥, снайперское 🎯, ближний бой 🗡️. Навык растёт **от использования** (+1 за выстрел, +1 за попадание, +2 за добивание; шкала 0–100, ранги Новичок → Стрелок → Ветеран → Эксперт → МАСТЕР). Бонусы: до **+25 точности** и **−1 ОД** на выстрел с навыка 50.
- 🔫 **22 вида оружия** в 5 ветках с **полным балансом рамок как в TIO**: у каждого ствола три дистанции — **мёртвая зона (min)**, оптимал (opt) и предел (max). Снайперки **не стреляют в упор** (СВД min 3, Barrett min 4 — пёс-раш контрит снайпера!), автоматы и пулемёты неудобны вплотную (min 2), базука не стреляет ближе 3 (самоподрыв), дробовики наоборот — **только вблизи** (max 5), пистолеты можно в упор, но недалеко (max 7–8). На прицеле виден «❌близко» в мёртвой зоне, подсказки объясняют причину («смени оружие 🔁»). ИИ-снайперы **отступают**, когда их прижали. Баланс по урону за 1 ОД выверен: ближний бой premium (риск), миниган и Barrett — топ за свои деньги, кулаки — слабейшие.
- 👊 **Кулаки и полное снятие оружия как в TIO**: оружие можно снять совсем — боец дерётся кулаками (4–8, 3 ОД), из кулаков можно вооружиться обратно. Клыки/кирку у пса и мутанта снять нельзя.
- 💉💣 Аптечки и осколочные гранаты (урон по площади 3×3).
- 🛒 Магазин, сгруппированный по веткам навыков; броня (3 уровня), импланты.
- 🎒 **Инвентарь и склад как в TIO**: у каждого бойца слоты — основное оружие, **запасное оружие** (смена в бою 🔁 за 2 ОД), броня, 2 импланта и **пояс** (до 3 аптечек + 3 гранат). В бой идёт только то, что на поясе бойца, остатки возвращаются после боя. Перед боем — кнопка 🎒 быстрой экипировки прямо из выбора отряда (с предупреждением о пустом поясе). Пёс пояс и броню не носит.
- 📦 **Склад отряда**: красивая сетка карточек с **детальными SVG-иконками каждого предмета** и цветными рамками редкости (серый/зелёный/синий/фиолетовый), контекстное меню предмета, продажа скупщику (50%), и **он-чейн листинги** — выставляй вещи на продажу другим игрокам.
- 🔧 **Мастерская (крафт как в TIO)**: материалы падают с убитых врагов (обыск трупов после победы) — металлолом, шкуры мутантов, композит, синий кристалл. Рецепты: самодельный/композитный/кристаллический панцирь (-13!), аптечки, гранаты, мачете и **попоны для псов** 🐕 (кожаная/кевларовая/«Цербер» -8) — собачья броня нигде больше не достаётся, носит её только пёс.
- 🎮 **Арена — комнаты боёв как в TIO**: режимы **1×1 (дуэль), 2×2, 4×4**, создание своей комнаты или вход в открытые, **ставки кредитами** (победитель забирает банк: +35/−20 рейтинга), «🚿 голые бои» без экипировки — самые честные. Соперники подбираются по рейтингу, сила и снаряжение масштабируются.
- ⛓️ **TIOArena.sol** — он-чейн комнаты: эскроу ставок, подтверждение результата двумя подписями с совпадающим hash боя, банк победителю. Команды sync.mjs: `room-create`, `room-join`, `room-result`, `rooms`.
- ⛓️ **Он-чейн предметы и торговля**: контракт `TIOItems` (TVM Solidity) — балансы предметов по pubkey, кредиты, NPC-магазин, **рынок игроков с эскроу** (listItem/unlist/buy), прямые переводы предметов друзьям. Управление через `chain/sync.mjs`: `items`, `list`, `unlist`, `buy`, `gift`, `market`.
- 🤝 Биржа наёмников, отряд до 6 бойцов, в бой — до 3.
- ⭐ Прокачка: опыт за бои, уровни (+HP, +точность, +ОД) — поверх навыков оружия.
- 🗺️ 5 миссий: от бандитской штольни до конвоя «Спектры» с пулемётчиками.
- 🏆 Рейтинг (+25 за победу / −15 за поражение), hash каждого боя.
- 🎨 **Улучшенная графика**: текстурированная земля с трещинами и камешками (пререндер-слой для скорости), тени и блики у объектов, светящиеся радиоактивные бочки, вспышки выстрелов, трассеры со свечением, искры попаданий, объёмные взрывы, тряска экрана, пыль в воздухе, виньетка, пульсирующий маркер выбора, Retina-рендер (devicePixelRatio).
- 📱 **PWA**: ставится на главный экран телефона, работает офлайн.
- ⛓️ Экран «Профиль / Acki Nacki»: проверка связи с Shellnet, чтение контракта, payload для он-чейн записи.
- 💾 Старые сейвы v1 подхватываются автоматически (миграция навыков).

## Как поиграть прямо сейчас (0 ₽, 2 минуты)

**Вариант А — мгновенно:** открой `index.html` в браузере (можно прямо из превью воркспейса).

**Вариант Б — на телефоне как приложение (бесплатный хостинг GitHub Pages):**
1. Создай бесплатный репозиторий на GitHub, залей папку `tio-nacki`.
2. Settings → Pages → Deploy from branch → `main` → корень.
3. Открой выданную ссылку на телефоне → «Добавить на главный экран». Готово: полноэкранная игра с иконкой, работает офлайн.

**Вариант В — Telegram Mini App (тоже бесплатно):**
1. Напиши @BotFather → `/newbot` → получи бота.
2. `/newapp` → укажи URL из варианта Б.
3. Игра открывается внутри Telegram, ссылкой можно делиться с друзьями.

## Блокчейн Acki Nacki (всё бесплатно, тестовая сеть Shellnet)

Архитектура — «лёгкий он-чейн»: бой считается на телефоне, а в смарт-контракт `TIOProfiles` пишутся **ник, рейтинг, победы/поражения и hash боя**. Это быстро, бесплатно и не заставляет ждать транзакцию каждый ход.

### Деплой контракта (один раз)

Acki Nacki использует TVM Solidity. Шаги по официальному гайду (https://dev.ackinacki.com):

```bash
# 1. Инструменты (бесплатно)
# solc для TVM + tvm-cli — см. https://dev.ackinacki.com (раздел Getting Started)

# 2. Компиляция
solc TIOProfiles.sol          # получим TIOProfiles.tvc и TIOProfiles.abi.json

# 3. Ключи деплоера
tvm-cli genphrase --dump deploy.keys.json

# 4. Узнать будущий адрес
tvm-cli genaddr TIOProfiles.tvc --setkey deploy.keys.json --save

# 5. Получить ТЕСТОВЫЕ токены SHELL на этот адрес — бесплатно:
#    https://docs.ackinacki.com → "Get test tokens from giver in Shellnet"

# 6. Деплой (value = сколько SHELL сконвертировать в VMSHELL на газ)
tvm-cli -u shellnet.ackinacki.org deploy TIOProfiles.tvc '{"value":1000000000}' \
   --abi TIOProfiles.abi.json --sign deploy.keys.json
```

Адрес контракта вставь в игре: **Профиль → Адрес контракта TIOProfiles**.

### Синхронизация результатов

```bash
cd chain
npm i @tvmsdk/core @tvmsdk/lib-node     # официальный SDK Acki Nacki
node sync.mjs init                       # ключи игрока (твой он-чейн ID)
node sync.mjs profile "Хмурый" 1000      # создать профиль он-чейн
node sync.mjs battle win 1025 0x1a2b3c4d # записать бой
node sync.mjs read                       # прочитать профиль (бесплатный get-метод)
```

Чтение состояния контракта из самой игры идёт напрямую через GraphQL Shellnet — без ключей и без затрат.

## Структура

```
tio-nacki/
├── index.html        # вся игра (один файл: движок, UI, данные)
├── manifest.json     # PWA-манифест
├── sw.js             # service worker (офлайн)
├── icon-192/512.png  # иконки
└── chain/
    ├── TIOProfiles.sol  # контракт профилей/рейтинга (TVM Solidity)
    ├── TIOItems.sol     # контракт предметов + рынок игроков (эскроу-торговля)
    ├── TIOArena.sol     # контракт PvP-комнат (1x1/2x2/4x4, ставки, 2 подписи)
    └── sync.mjs         # клиент всех контрактов через TVM SDK
```
